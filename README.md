# VINYL PILOT — VST3 prototype v0.1

Интерактивный виниловый аудиоэффект для Ableton Live. Написан на C++17/JUCE 8;
планируется последующая сборка того же движка как Audio Unit для Logic Pro.

## Что уже реализовано

- Крутящаяся пластинка в окне плагина при воспроизведении транспорта.
- Мышь: схватить пластинку, крутить назад или вперёд, остановить, отпустить.
- **Surface Noise** — отдельно регулируемый шорох/шум поверхности.
- **Dust & Pops** — отдельные случайные щелчки.
- **Vinyl Wear** — приглушение ВЧ и лёгкие wow/flutter.
- **Dry / Wet** — смешивание исходного и обработанного звука.
- **Scratch Speed** — параметр VST3 для Automation: `-3` обратный ход,
  `0` остановка, `1` обычная скорость, `+3` ускорение.
- **Return (ms)** — заданное время возвращения к текущему фрагменту
  дорожки в Ableton. Скорость плавно изменяется, и по завершении
  дорожка снова синхронизирована с транспортом.
- **Pitch Wheel Range** + **Receive Pitch Bend** — опционально обработка
  MIDI pitch bend, если хост действительно доставляет MIDI плагину.

История звука — около 12 секунд. Плагин имеет заявленную задержку **125 мс**,
компенсируемую DAW. Она нужна, чтобы было немного «будущих» относительно
слышимого участка сэмплов для ускоренного движения вперёд.
При очень долгом скретче назад история исчерпывается. При очень длительном
ускорении вперёд чтение упирается в последний доступный сэмпл: без
предзагрузки полного файла плагин не может читать аудио из будущего.

## Сборка на macOS (Intel или Apple Silicon)

### Готовая сборка через GitHub Actions

В `.github/workflows/build-macos-vst3.yml` есть универсальная сборка
`arm64 + x86_64` на macOS (`macos-15`): после загрузки папки `VinylPilot` в корень
GitHub-репозитория запусти workflow **Build Vinyl Pilot VST3 for Apple Silicon**
через вкладку Actions (в корне репозитория должно лежать **содержимое** папки
`VinylPilot`, включая скрытую `.github`). Скачай артефакт
`VinylPilot_Universal_VST3`, распакуй его
и затем распакуй `VinylPilot_Universal_VST3.zip`. Внутри — пакет
`Vinyl Pilot.vst3`, предназначенный для папки
`~/Library/Audio/Plug-Ins/VST3/`. Для запуска Actions нужен GitHub-репозиторий.

### Локальная сборка

Нужны Xcode с Command Line Tools, CMake 3.22+, Git и сеть при первой сборке
(скачивается JUCE 8.0.8). Из терминала в каталоге проекта:

```bash
chmod +x ./build-mac.sh
./build-mac.sh
```

При уже скачанном JUCE:

```bash
JUCE_DIR=/путь/к/JUCE ./build-mac.sh
```

Полученный `Vinyl Pilot.vst3` будет в
`build/VinylPilot_artefacts/Release/VST3/`.
Скопируй весь пакет `.vst3` в `~/Library/Audio/Plug-Ins/VST3/`, затем
запусти Ableton Live и включи VST3 в настройках Plug-Ins; при необходимости
выполни повторное сканирование. На macOS незаверенный локальный плагин может
потребовать разрешения в системных настройках безопасности.

### Быстрый тест в Ableton

1. Добавь VST3 Vinyl Pilot на **аудиодорожку** с непрерывным музыкальным фрагментом.
2. Нажми Play — пластинка должна вращаться. Меняй Surface Noise.
3. Схвати мышью пластинку, вращай вперёд и назад, отпусти. Подними Return
   до 2000 мс, чтобы отчётливо услышать возвращение к живой позиции.
4. Для automation нажми **Configure** в панели VST3 Live (если параметр ещё
   не отображён), подвигай Scratch Speed, затем создай automation lane и
   рисуй огибающую. Нормальное значение — **1.0**, не ноль.
5. Через MIDI Map Live (`Cmd+M`) привяжи к Scratch Speed обычный MIDI
   фейдер/энкодер KeyLab 49. Убедись, что после скретча значение возвращается
   к 1.0, иначе намеренно продолжается неединичная скорость.

### Pitch wheel KeyLab 49

Оригинальное колесо Pitch Bend обычно передаёт **Pitch Bend**, а не MIDI CC.
Это особый тип события: стандартный MIDI Mapping в Live часто не позволяет
привязать его как обычный фейдер. Прямой режим в плагине работает только когда
Live маршрутизирует MIDI pitch bend на его вход (для VST3-аудиоэффектов такое
поведение зависит от конкретной маршрутизации хоста).

Если колесо не работает при обычной загрузке на аудиотрек:

- Для первого теста используй любой переназначаемый CC-фейдер KeyLab.
- Для именно Pitch Wheel в Live потребуется отдельный способ преобразовать
  Pitch Bend в CC/автоматизацию, например Max for Live, либо особая
  MIDI-маршрутизация, если она доступна в твоей версии Live.
- Не пытайся менять Pitch Wheel в Arturia MIDI Control Center на CC без
  проверки конкретного поколения клавиатуры: у некоторых KeyLab это запрещено.

## Инженерные ограничения первого прототипа

- Обработка в реальном времени с линейной интерполяцией; резкое вращение
  или очень большое ускорение может давать цифровые артефакты — в скретче это
  пока допустимо. В следующей версии можно улучшить ресемплинг.
- Внешнее воспроизведение аудио и видеосинхронизация проверены только
  алгоритмически, без реального запуска в Ableton/Logic на Mac.
- Мотор возвращается к хостовому аудио потоку, а не перемещает настоящий
  плейхед Ableton. Это именно аудиоэффект, который не меняет транспорт DAW.
- MIDI pitch bend в VST3 иногда не передаётся хостом. Автоматизация Scratch
  Speed поддерживается независимо от MIDI.
- JUCE 8 имеет условия лицензирования, которые стоит проверить перед
  коммерческой публикацией; код прототипа можно пока тестировать локально.

## Тест звукового движка без JUCE

Тесты не требуют SDK, CMake или macOS:

```bash
g++ -std=c++17 -O2 -Wall -Wextra -pedantic Tests/EngineTests.cpp -o /tmp/vinyl-pilot-tests
/tmp/vinyl-pilot-tests
```

Проверяются точная заявленная задержка, остановка, реверс, возврат к живой
позиции за нужное время и работа Surface Noise.
